# SOP-003 Suspected Adverse Event Intake

> FICTIONAL training document for the Pharma Safety Intake & Triage Tracker prototype. Not a real procedure.

## Purpose
This procedure covers the capture of suspected adverse event reports, meaning any untoward medical occurrence that a reporter describes after use of a company product. The intake role is to record what was reported, completely and accurately. Intake operators never judge whether the product is responsible for the event and never offer medical advice; a reporter who needs medical help is directed to a healthcare professional.

## Minimum information
A suspected adverse event report needs a reporter type, the product name, the batch or lot number when available, a description of what was reported, an event description and the event onset date. The event onset date is the date the reporter says the event began. It cannot be later than the date the report was received, and it cannot be in the future. If the reporter does not know the exact date, record the best available date and say so in the event description.

## Recording the event description
Record the event in the reporter's own words first, then add standard clinical terminology where the meaning is unambiguous. Examples of standard terms used in this training corpus: dyspnea for laboured respiration, urticaria for hives, pruritus for itching, nausea and emesis for stomach upset and vomiting, syncope for fainting, dizziness, headache, erythema at an application site and anaphylaxis for a severe generalised allergic reaction. Respiratory events such as dyspnea or wheezing are always given priority in the triage queue.

## What intake operators must not do
Operators must not state or imply that the product produced the event, must not suggest stopping, continuing or changing a medicine, and must not classify the case as serious or non-serious. They also do not decide whether any authority needs to be informed. Those activities belong to qualified pharmacovigilance personnel working in the enterprise safety system. The knowledge assistant refuses questions of this kind.

## Follow-up information
When a reporter calls back with new information about an existing case, the operator quotes the existing reference number and the triage team adds the information during review. Never create a second report for the same event from the same reporter. If the reporter describes a different event, start a new report.
